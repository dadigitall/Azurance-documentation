L'éligibilité prestataire est une pré-vérification ERP lorsqu'elle est appelée avec `purpose=PRECHECK`. Elle ne crée pas de claim, ne réserve pas de plafond et ne modifie pas le contrat. Le périmètre prestataire et assureur autorisé est déterminé par `X-Api-Key`.

À la soumission d'un claim, Azurance relance une vérification finale `CLAIM_SUBMISSION`. Cette vérification valide la couverture, le réseau et les plafonds, puis Azurance réserve les plafonds si le claim est accepté.

## Vérifier une couverture

```http
POST /api/v1/eligibility/check
```

### Body

```json
{
  "identifier": "POL-SBX-000001",
  "coverage_code": "CONSULTATION_GP",
  "amount": 15000,
  "purpose": "PRECHECK"
}
```

| Champ | Requis | Description |
| --- | --- | --- |
| `identifier` | Oui | Numéro de police, souscription, UUID titulaire ou identifiant accepté par l'assureur. |
| `coverage_code` | Oui | Code de garantie à vérifier. |
| `amount` | Non | Montant estimé ou final. |
| `purpose` | Non | `PRECHECK` par défaut. `CLAIM_SUBMISSION` est réservé à la vérification finale. |
| `service_date` | Non | Date de service utilisée pour vérifier contrat actif, période et plafonds. |

```ts
const response = await fetch("https://provider-api.elenami.com/api/v1/eligibility/check", {
  method: "POST",
  headers: {
    Accept: "application/json",
    "Content-Type": "application/json",
    "X-Api-Key": process.env.AZURANCE_PROVIDER_API_KEY!,
    "X-Request-Id": "erp-precheck-001"
  },
  body: JSON.stringify({
    identifier: "POL-SBX-000001",
    coverage_code: "CONSULTATION_GP",
    amount: 15000,
    purpose: "PRECHECK"
  })
})

const eligibility = await response.json()
```

## Carte membre

```http
POST /api/v1/eligibility/member-card
```

```json
{
  "identifier": "POL-SBX-000001"
}
```

Utilisez cette route après identification de l'assuré pour afficher une fiche synthétique. Elle ne remplace pas `POST /api/v1/eligibility/check` avant facturation ou claim.

## Plafonds

Les plafonds v1 sont calculés sur:

| Plafond | Description |
| --- | --- |
| Global souscription | Plafond annuel global du contrat ou de la souscription. |
| Couverture annuelle | Plafond annuel de la garantie demandée. |

Les plafonds impactent la part assureur, pas le montant brut facturé. Une réponse peut donc refuser si `reimbursement_amount` dépasse `remaining_global` ou `remaining_coverage`.

Codes métier possibles:

| Code | Description |
| --- | --- |
| `GLOBAL_LIMIT_EXCEEDED` | La part assureur dépasse le plafond global restant. |
| `COVERAGE_LIMIT_EXCEEDED` | La part assureur dépasse le plafond de couverture restant. |
| `LIMIT_EXCEEDED` | Refus générique de réservation de plafond. |
