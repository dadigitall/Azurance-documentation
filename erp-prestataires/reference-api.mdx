La section **Référence API** est la documentation détaillée pour les intégrateurs ERP. Chaque endpoint y expose:

- les headers, paramètres d'URL et query params;
- les champs requis et optionnels du body;
- la description métier de chaque champ;
- les exemples de requête et de réponse;
- les erreurs possibles;
- les snippets `curl`, TypeScript, JavaScript, PHP, Java et C# générés par Mintlify.

## Lecture des champs

| Indication | Sens |
| --- | --- |
| `Required` | Champ obligatoire. L'appel est rejeté si le champ est absent ou vide. |
| `Optional` | Champ optionnel. Il peut être omis, sauf règle métier contextualisée. |
| `nullable` | Champ qui peut exister avec la valeur `null`. |
| `enum` | Valeurs acceptées exclusivement. Toute autre valeur retourne une erreur de validation. |
| `format: uuid` | Identifiant public stable au format UUID. |
| `format: date` | Date civile au format `YYYY-MM-DD`. |
| `format: date-time` | Date heure ISO 8601 avec fuseau, par exemple `2026-05-26T12:30:00Z`. |

## Headers communs

| Header | Requis | Description |
| --- | --- | --- |
| `X-Api-Key` | Oui | Clé API prestataire. Elle détermine le prestataire, l'organisation assureur, l'environnement et les scopes. |
| `X-Request-Id` | Non | Identifiant de corrélation fourni par l'ERP pour suivre une opération dans les logs et audits. |
| `Idempotency-Key` | Selon endpoint | Clé stable pour éviter les doublons sur les créations rejouables après timeout. |

Envoyez uniquement les champs documentés pour chaque endpoint. Les informations de périmètre sont déterminées par la clé API.

## Réponses et erreurs

Les réponses `2xx` décrivent le résultat métier attendu. Les réponses `4xx` indiquent une erreur côté ERP, clé API, scopes, consentement, validation métier ou idempotence. Les réponses `5xx` indiquent une indisponibilité temporaire du service.

Les erreurs stables sont documentées dans [Erreurs API](/commun/erreurs). Pour les opérations critiques, conservez toujours `X-Request-Id` côté ERP: c'est la valeur à transmettre au support pour retrouver l'audit corrélé.
