---
title: "Consulter une prestation effectuée"
description: "Retourne le détail d'une prestation exécutée."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/service-executions/{serviceExecutionUid}"
---

Cet endpoint retourne le détail d'une prestation enregistrée via `POST /api/v1/service-executions` : personne couverte, type de couverture, date, lignes de prestation et snapshot de consentement.

## Scope requis

`service_executions.create` (ou scope de lecture équivalent selon la configuration de la clé).

## Paramètre de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `serviceExecutionUid` | string | Identifiant de la prestation. |

## Réponse

La réponse contient les informations de la prestation : statut, montants, lignes `items` et `consent_snapshot`. Pour soumettre un claim sur cette prestation, utilisez `POST /api/v1/claims` en référençant le `service_execution_uid`.
