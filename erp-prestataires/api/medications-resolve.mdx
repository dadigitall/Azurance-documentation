---
title: "Résoudre un médicament"
description: "Résout un libellé libre vers un médicament du référentiel."
openapi: "/openapi/provider-api.openapi.yml POST /api/v1/reference/medications/resolve"
---

Cet endpoint résout un libellé libre (saisie pharmacien, désignation ERP, ligne d'ordonnance) vers le ou les produits médicaments du référentiel pivot Azurance les plus pertinents. Il est conçu pour l'enrichissement automatique des lignes de prescription ou de dispensation.

## Scope requis

`reference.medications.view`

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `label` | string | oui | Libellé libre à résoudre (min 2, max 300). |
| `country_code` | string | non | Pays du référentiel (`BJ` par défaut). |
| `limit` | integer | non | Nombre maximum de candidats (max 20, défaut 5). |

## Réponse

La réponse contient trois champs :

| Champ | Type | Description |
| --- | --- | --- |
| `best_match` | object\|null | Meilleur candidat `MedicationProduct` ou `null` si aucun match. |
| `candidates` | array | Tableau de `MedicationProduct` candidats (jusqu'à `limit`). |
| `confidence` | number | Score de confiance global du best match (0 à 1). |

### Champs de `MedicationProduct`

| Champ | Type | Description |
| --- | --- | --- |
| `uid` | uuid | Identifiant public du produit médicament. |
| `country_code` | string | Pays du référentiel produit. |
| `market_status` | string | Statut commercial. |
| `source` | string | Source d'import. |
| `source_details` | object | Détails de la source. |
| `designation` | string | Désignation officielle ou importée. |
| `display_name` | string | Nom d'affichage. |
| `dci_raw` | string | DCI/substances. |
| `inn_name` | string | Dénomination commune internationale. |
| `marketing_authorization_holder` | string | Titulaire de l'AMM. |
| `origin_country` | string | Pays d'origine. |
| `public_price` | number | Prix public. |
| `authorization_number` | string | Numéro AMM. |
| `authorization_expires_at` | date | Date d'expiration de l'autorisation. |
| `source_url` | string | URL source. |
| `is_active` | boolean | Produit actif. |
| `resolve_confidence` | number | Score de confiance individuel (0 à 1). |
| `presentations` | array | Présentations (si chargées). |
| `clinical_mapping` | object | Mapping clinique ATC/RxCUI (si chargé). |
| `mappings` | array | Mappings cliniques complets (si chargés). |

## Exemple de requête

```json
{
  "label": "paracetamol 500mg comprime",
  "country_code": "BJ",
  "limit": 5
}
```
