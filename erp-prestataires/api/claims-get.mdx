---
title: "Consulter un claim"
description: "Retourne le claim, ses documents, snapshots, réservations et décisions."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/claims/{claimId}"
---

Cet endpoint retourne le détail complet d'un claim : statut, montants, lignes de prestation, documents rattachés, snapshots d'éligibilité, réservations de plafond et décisions de l'assureur. Il est utilisé pour le suivi du remboursement côté ERP.

## Scope requis

`claims.view`

## Paramètre de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `claimId` | string | Identifiant du claim. |

## Réponse

La réponse contient le claim avec :

- les lignes `items` et les montants (`amount_claimed`, montant éligible, montant remboursé) ;
- la liste des documents justificatifs ;
- les snapshots d'éligibilité et les réservations de plafond ;
- l'historique des décisions et le statut courant.

Si le claim n'existe pas ou n'est pas visible par le prestataire, l'API retourne une erreur `404`. Pour lister l'ensemble des claims, utilisez `GET /api/v1/claims`.
