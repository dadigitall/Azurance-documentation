---
title: "Lister les webhooks"
description: "Liste les webhooks configurés par le prestataire."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/webhook-subscriptions"
---

Cet endpoint liste les souscriptions webhook configurées par le prestataire authentifié. Il permet de vérifier les URLs actives, les event_types souscrits et l'état d'activation de chaque souscription.

## Scope requis

`billing.webhooks.manage`

## Réponse

La réponse contient un tableau de souscriptions avec, pour chacune :

- `uuid` : identifiant de la souscription ;
- `name` : nom lisible ;
- `target_url` : URL de réception HTTPS ;
- `event_types` : événements souscrits ;
- `is_active` : état d'activation.

Pour modifier une souscription, utilisez `PATCH /api/v1/webhook-subscriptions/{uuid}` ; pour la supprimer, `DELETE /api/v1/webhook-subscriptions/{uuid}`.

## Exemple de réponse

```json
{
  "data": [
    {
      "uuid": "wh_sandbox_001",
      "provider_uid": "prov_sandbox_001",
      "event_types": [
        "claim.status_changed",
        "payment.completed"
      ],
      "url": "https://erp.example.com/webhooks/azurance",
      "status": "active",
      "created_at": "2025-01-15T10:00:00Z",
      "last_triggered_at": "2025-01-16T14:30:00Z"
    }
  ],
  "meta": {
    "current_page": 1,
    "per_page": 20,
    "total_count": 3,
    "total_pages": 1
  }
}
```
