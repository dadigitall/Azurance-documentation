---
title: "Dossier médical"
description: "Récupère le dossier médical complet d'un assuré, avec traitements et antécédents chirurgicaux calculés."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/insured/{insuredUid}/medical-record"
---

Cet endpoint retourne le dossier médical complet d'un assuré. Il combine :

- **Données saisies** par les prestataires : groupe sanguin, taille, poids, allergies, pathologies chroniques, vaccinations, antécédents familiaux, mode de vie.
- **Traitements en cours** (`current_medications`) : calculés automatiquement à partir des prescriptions actives de l'assuré, croisés avec les claims soumis pour indiquer si chaque médicament a été effectivement consommé (`consumed: true/false`).
- **Antécédents chirurgicaux** (`surgical_history`) : calculés automatiquement à partir des actes médicaux de catégorie `surgery` déclarés lors des consultations.

Les sections calculées ne sont pas saisissables manuellement — elles se mettent à jour à chaque nouvelle prescription, acte médical ou claim soumis.

## Scope requis

`clinical.records.view`

Selon le contexte, un consentement fort de l'assuré peut être requis avant la lecture.

## Paramètres de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `insuredUid` | string | Identifiant de l'assuré. |

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.

## Cache

Les fragments du dossier médical sont mis en cache côté BFF (Redis) avec des TTL différenciés :

| Fragment | TTL |
| --- | --- |
| Données saisies (allergies, pathologies, etc.) | 30 min |
| `current_medications` | 15 min |
| `surgical_history` | 1 h |

Le cache est invalidé proactivement lors d'une modification (PUT medical-record, nouvelle prescription, acte chirurgical, soumission de claim).

## Champs `current_medications` (vue calculée)

| Champ | Type | Description |
| --- | --- | --- |
| `medication_name` | string \| null | Nom du médicament (depuis la ligne de prescription). |
| `medication_code` | string \| null | Code du médicament (référentiel local ou ATC). |
| `dosage` | string \| null | Dosage (ex: `500mg`). |
| `frequency` | string \| null | Fréquence (ex: `2x/jour`). |
| `duration` | string \| null | Durée du traitement. |
| `prescribed_at` | string \| null | Date d'émission de la prescription. |
| `prescriber_name` | string \| null | Nom du prescripteur. |
| `valid_until` | string \| null | Date de validité de la prescription. |
| `prescription_uid` | string | UID de la prescription. |
| `consumed` | boolean | `true` si un claim non-rejeté contient ce médicament. |
| `last_dispensed_at` | string \| null | Date du dernier claim contenant ce médicament. |
| `last_dispensed_quantity` | number \| null | Quantité dispensée lors du dernier claim. |
| `last_claim_uuid` | string \| null | UUID du dernier claim. |
| `last_claim_status` | string \| null | Statut du dernier claim. |

## Champs `surgical_history` (vue calculée)

| Champ | Type | Description |
| --- | --- | --- |
| `act_code` | string \| null | Code de l'acte (CCAM ou ICHI). |
| `act_label` | string \| null | Libellé de l'acte. |
| `performed_at` | string \| null | Date d'exécution de l'acte. |
| `performed_by` | string \| null | Praticien ayant réalisé l'acte. |
| `encounter_date` | string \| null | Date de la consultation parente. |
| `encounter_type` | string \| null | Type de consultation. |
| `provider_uid` | string \| null | UID du prestataire. |
| `encounter_uid` | string \| null | UID de la consultation. |
