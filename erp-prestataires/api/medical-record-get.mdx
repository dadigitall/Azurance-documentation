---
title: "Dossier médical"
description: "Récupère le dossier médical d'un assuré."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/insured/{insuredUid}/medical-record"
---

Cet endpoint retourne le dossier médical complet d'un assuré : groupe sanguin, taille, poids, allergies, pathologies chroniques, antécédents chirurgicaux, vaccinations, antécédents familiaux, mode de vie et traitements en cours.

## Scope requis

`clinical.records.view`

Selon le contexte, un consentement fort de l'assuré peut être requis avant la lecture.

## Paramètres de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `insuredUid` | string | Identifiant de l'assuré. |

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
