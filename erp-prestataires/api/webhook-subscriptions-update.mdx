---
title: "Modifier un webhook"
description: "Met à jour un webhook du prestataire."
openapi: "/openapi/provider-api.openapi.yml PATCH /api/v1/webhook-subscriptions/{uuid}"
---

Cet endpoint met à jour une souscription webhook existante. Il permet de modifier l'URL de réception, les event_types souscrits, le secret partagé ou l'état d'activation sans recréer la souscription.

## Scope requis

`billing.webhooks.manage`

## Paramètre de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `uuid` | uuid | Identifiant de la souscription webhook. |

## Champs modifiables

| Champ | Type | Description |
| --- | --- | --- |
| `name` | string | Nom lisible de la souscription. |
| `target_url` | string | URL HTTPS de réception. |
| `secret` | string | Nouveau secret partagé (minimum 16 caractères). |
| `event_types` | array | Nouvelle liste d'événements souscrits. |
| `is_active` | boolean | Active ou désactive la souscription. |

## Bonnes pratiques

Lorsque vous changez le `secret`, la nouvelle clé s'applique immédiatement aux livraisons suivantes : assurez-vous que le récepteur est prêt à vérifier la nouvelle signature. Pour une pause temporaire sans suppression, passez `is_active` à `false`.

## Exemple de réponse

```json
{
  "data": {
    "uuid": "wh_sandbox_001",
    "provider_uid": "prov_sandbox_001",
    "event_types": [
      "claim.status_changed",
      "payment.completed",
      "invoice.generated"
    ],
    "url": "https://erp.example.com/webhooks/azurance",
    "status": "active",
    "updated_at": "2025-01-16T10:00:00Z"
  }
}
```
