---
title: "Chronologie du dossier médical"
description: "Récupère la chronologie des événements du dossier médical."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/insured/{insuredUid}/medical-record/timeline"
---

Cet endpoint retourne la chronologie médicale complète d'un assuré : consultations, ordonnances et actes médicaux, triés par date décroissante. Il est utile pour reconstituer le parcours de soins ou générer un historique pour le patient.

## Scope requis

`clinical.records.view`

## Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `insuredUid` | string | oui | Identifiant de l'assuré (path). |
| `page` | integer | non | Numéro de page. |
| `per_page` | integer | non | Résultats par page. |

## Réponse

La réponse contient une liste paginée d'événements médicaux. Chaque événement inclut son type (consultation, ordonnance, acte), sa date, un libellé et un identifiant permettant de récupérer le détail via l'endpoint correspondant.

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
