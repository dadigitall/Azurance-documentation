---

Cet endpoint est un alias métier de `GET /api/v1/network/relationships`. Il retourne les mêmes données sous un chemin alternatif pour s'aligner sur le vocabulaire métier des ERP prestataires.

## Scope requis

`providers.network.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `status` | string | non | Filtrer par statut de relation (`ACTIVE`, `ENDED`). |

## Réponse

La réponse est identique à `/api/v1/network/relationships` : un tableau de relations avec l'identifiant de l'assureur, le type, le statut et le niveau réseau.
