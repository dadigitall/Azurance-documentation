---
title: "Synthèse du dossier médical"
description: "Récupère la synthèse du dossier médical d'un assuré."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/insured/{insuredUid}/medical-record/summary"
---

Cet endpoint retourne une synthèse condensée du dossier médical : allergies critiques, pathologies actives, groupe sanguin et traitements en cours. Il est conçu pour un affichage rapide en contexte clinique (urgences, admission) sans charger le dossier complet.

## Scope requis

`clinical.records.view`

## Paramètres de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `insuredUid` | string | Identifiant de l'assuré. |

## Différence avec le dossier complet

- `GET /api/v1/insured/{insuredUid}/medical-record` retourne le dossier complet avec l'historique détaillé.
- `GET /api/v1/insured/{insuredUid}/medical-record/summary` retourne uniquement les informations critiques pour une décision clinique immédiate.

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
