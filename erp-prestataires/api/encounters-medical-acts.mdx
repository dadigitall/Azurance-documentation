description: "Liste les actes médicaux rattachés à une consultation."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/encounters/{encounterId}/medical-acts"
---

Cet endpoint liste les actes médicaux rattachés à une consultation. Pour ajouter un acte, utilisez `POST /api/v1/encounters/{encounterId}/medical-acts` (voir [Ajouter un acte médical](/erp-prestataires/api/encounters-medical-acts-add)).

## Scope requis

`clinical.encounters.view`

## Paramètres de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `encounterId` | string | Identifiant UUID de la consultation. |

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
