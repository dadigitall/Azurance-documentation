---
title: "Recherche médicaments"
description: "Recherche full-text dans le référentiel médicaments."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/reference/medications/search"
---

Cet endpoint effectue une recherche full-text dans le référentiel médicaments. Il est conçu pour l'autocomplétion et la sélection d'un produit lors de la saisie d'une prescription ou d'une dispensation.

## Scope requis

`reference.medications.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `q` | string | oui | Terme de recherche (min 2 caractères, max 200). |
| `country_code` | string | non | Pays du référentiel (`BJ` par défaut). |
| `market_status` | string | non | Filtre le statut commercial. |
| `limit` | integer | non | Nombre maximum de résultats (max 50, défaut 20). |

## Réponse

La réponse contient un tableau `data` de `MedicationProduct` correspondant au terme de recherche, trié par pertinence décroissante. L'objet `meta` indique la source de recherche et le nombre total de résultats.

## Champs de réponse (`MedicationProduct`)

| Champ | Type | Description |
| --- | --- | --- |
| `uid` | uuid | Identifiant public du produit médicament. |
| `country_code` | string | Pays du référentiel produit. |
| `market_status` | string | Statut commercial. |
| `source` | string | Source d'import. |
| `source_details` | object | Détails de la source. |
| `designation` | string | Désignation officielle ou importée. |
| `display_name` | string | Nom d'affichage. |
| `dci_raw` | string | DCI/substances. |
| `inn_name` | string | Dénomination commune internationale. |
| `marketing_authorization_holder` | string | Titulaire de l'AMM. |
| `origin_country` | string | Pays d'origine. |
| `public_price` | number | Prix public. |
| `authorization_number` | string | Numéro AMM. |
| `authorization_expires_at` | date | Date d'expiration de l'autorisation. |
| `source_url` | string | URL source. |
| `is_active` | boolean | Produit actif. |
| `presentations` | array | Présentations (si chargées). |
| `clinical_mapping` | object | Mapping clinique ATC/RxCUI (si chargé). |
| `mappings` | array | Mappings cliniques complets (si chargés). |

## Exemple de requête

```
GET /api/v1/reference/medications/search?q=paracetamol&country_code=BJ&limit=10
```
