---
title: "Lister les assureurs conventionnés"
description: "Liste les compagnies d'assurance et réseaux en relation avec le prestataire."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/network/relationships"
---

Cet endpoint liste les relations entre le prestataire authentifié et les compagnies d'assurance. Chaque relation indique le statut (`ACTIVE`, `ENDED`), le niveau réseau (`PREFERRED`, `IN_NETWORK`, `OUT_OF_NETWORK`) et l'identifiant public de la relation.

## Scope requis

`providers.network.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `status` | string | non | Filtrer par statut de relation (`ACTIVE`, `ENDED`). |

## Réponse

La réponse contient un tableau de relations. Chaque entrée inclut l'identifiant de l'assureur, le type de relation, le statut et le niveau réseau. Utilisez ces informations pour déterminer quels assureurs acceptent vos claims et sous quelles conditions.
