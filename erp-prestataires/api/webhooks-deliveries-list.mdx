---
title: "Lister les livraisons webhook"
description: "Récupère l'historique des tentatives de livraison d'un abonnement webhook."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/webhooks/{uuid}/deliveries"
---

Cet endpoint retourne l'historique paginé des tentatives de livraison des événements webhook pour un abonnement donné. Utilisez-le pour auditer les livraisons, diagnostiquer les échecs et identifier les livraisons à relancer.

## Scope requis

`provider.webhooks.view`

## Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uuid` (path) | string | oui | UUID de l'abonnement webhook. |
| `per_page` (query) | integer | non | Nombre de livraisons par page (1-100, défaut 20). |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data` | array | Liste des livraisons. |
| `data[].uuid` | string | Identifiant unique de la livraison. |
| `data[].event_id` | string | Identifiant unique de l'événement. Utiliser pour dédupliquer. |
| `data[].event_type` | string | Type d'événement livré. |
| `data[].status` | string | Statut (`PENDING`, `DELIVERED`, `FAILED`). |
| `data[].attempts` | integer | Nombre de tentatives. |
| `data[].response_status` | integer | Code HTTP de la dernière réponse. |
| `data[].next_retry_at` | string | Date de la prochaine tentative. |
| `data[].delivered_at` | string | Date de livraison réussie. |
| `data[].last_error` | string | Message d'erreur de la dernière tentative. |
| `meta` | object | Métadonnées de pagination. |

## Statuts de livraison

| Statut | Description |
| --- | --- |
| `PENDING` | Livraison en attente ou programmée pour retry. |
| `DELIVERED` | Livraison réussie (réponse 2xx). |
| `FAILED` | Livraison définitivement échouée. |
