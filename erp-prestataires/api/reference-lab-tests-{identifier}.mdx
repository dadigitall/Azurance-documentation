Retourne le détail complet d'une analyse du référentiel LOINC FR à partir de son code LOINC.

## Scope requis

`reference.lab_tests.view`

## Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `identifier` | path | Oui | Code LOINC (ex: `2339-0`) |

## Exemple de requête

```bash
curl --request GET \
  --url "https://provider-api-sandbox.elenami.com/api/v1/reference/lab-tests/2339-0" \
  --header "X-Api-Key: $AZURANCE_PROVIDER_API_KEY"
```

## Erreurs

| Code | Description |
| --- | --- |
| 401 | Clé API manquante ou invalide. |
| 403 | Scope `reference.lab_tests.view` manquant. |
| 404 | Code LOINC introuvable. |
