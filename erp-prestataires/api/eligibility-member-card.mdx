Cet endpoint résout un assuré à partir de son numéro de carte membre ou identifiant équivalent. Contrairement à `/eligibility/check` qui effectue un précheck de couverture, cet endpoint retourne les candidats `CoveredPerson` correspondant à l'identifiant (souscripteur et bénéficiaires rattachés) sans calculer un montant éligible.

## Scope requis

`eligibility.check`

## Cas d'usage

- Afficher les informations d'un assuré à l'accueil d'un établissement avant la consultation.
- Vérifier rapidement qu'un assuré est actif et récupérer ses identifiants (`covered_person_uid`, `subscription_uid`) pour les étapes suivantes (consentement, éligibilité, claim).
- Récupérer les métadonnées de souscription (`policy_number`, `subscription_number`, `member_number`) pour les stocker dans le dossier administratif.

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `identifier` | string | oui | Numéro de carte membre, numéro de police ou identifiant équivalent. |

## Réponse

La réponse contient un tableau `data` de candidats `CoveredPerson`. Chaque candidat décrit la personne couverte, sa souscription et son contexte. Si l'identifiant ne correspond à aucun assuré actif, l'API retourne une erreur `404`.

### Champs d'un candidat

| Champ | Type | Description |
| --- | --- | --- |
| `covered_person_type` | string | `policyholder` ou `beneficiary`. |
| `covered_person_uid` | string | Identifiant UUID de la personne couverte. |
| `identity_uid` | string | Identifiant d'identité fédérée. |
| `auth_user_uid` | string | Identifiant du compte assuré (si enrollé). |
| `policyholder_uid` | string | Identifiant UUID du souscripteur. |
| `policyholder_auth_user_uid` | string | Compte assuré du souscripteur (si enrollé). |
| `subscription_uid` | string | Identifiant UUID de la souscription. |
| `subscription_number` | string | Numéro de souscription. |
| `policy_number` | string | Numéro de police. |
| `member_number` | string | Numéro de membre. |
| `beneficiary_number` | string | Numéro de bénéficiaire (null pour un souscripteur). |
| `insurer_uid` | string | Identifiant de l'assureur. |
| `insurer_name` | string | Nom de l'assureur (null si non résolu). |
| `coverage_status` | string | Statut de couverture de la souscription. |
| `display_name` | string | Nom complet de la personne couverte. |
| `relationship` | string | Lien avec le souscripteur (`policyholder` pour le titulaire). |
| `date_of_birth` | string | Date de naissance (format date). |
| `contact` | object | Contact de la personne (`phone`, `email`). |
| `policyholder_contact` | object | Contact du souscripteur (`phone`, `email`). |
