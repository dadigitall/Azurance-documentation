---
title: "Lister les pré-autorisations"
description: "Liste les pré-autorisations du prestataire."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/prior-authorizations"
---

Cet endpoint liste les pré-autorisations du prestataire authentifié, avec possibilité de filtrer par statut. Il est utilisé pour piloter le back-office prestataire et suivre les demandes en cours.

## Scope requis

`prior_authorizations.view`

## Paramètres de requête

| Paramètre | Type | Description |
| --- | --- | --- |
| `status` | string | Filtre par statut (voir ci-dessous). |

## Statuts possibles

| `status` | Usage |
| --- | --- |
| `PENDING_REVIEW` | En attente de revue par l'assureur. |
| `INFO_NEEDED` | Pièces complémentaires attendues. |
| `APPROVED` | Accord préalable accordé. |
| `REJECTED` | Demande refusée. |
| `EXPIRED` | Accord expiré sans consommation. |
| `CANCELLED` | Demande annulée par le prestataire. |
| `CONSUMED` | Utilisée par un claim approuvé. |

## Réponse

La réponse est paginée et contient un tableau d'objets `PriorAuthorization`. Pour consulter le détail d'une demande, appelez `GET /api/v1/prior-authorizations/{uid}`.
