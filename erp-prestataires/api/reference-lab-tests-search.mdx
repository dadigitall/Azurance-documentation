---

Recherche textuelle dans le référentiel LOINC FR publié par l'Agence du Numérique en Santé (ANS).
La recherche porte sur le code LOINC, le libellé français, le composant français et anglais, et les synonymes.

## Scope requis

`reference.lab_tests.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `q` | string | Non | Terme de recherche (code LOINC, libellé, composant) |
| `limit` | integer | Non | Nombre de résultats (1-100, défaut 20) |
| `chapter` | string | Non | Filtrer par chapitre (ex: `Biochimie`, `Hématologie`) |
| `include_inactive` | boolean | Non | Inclure les analyses inactives (défaut: `false`) |

## Exemple de requête

```bash
curl --request GET \
  --url "https://provider-api-sandbox.elenami.com/api/v1/reference/lab-tests/search?q=glucose&limit=5" \
  --header "X-Api-Key: $AZURANCE_PROVIDER_API_KEY"
```
