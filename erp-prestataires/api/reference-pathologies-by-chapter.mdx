---
title: "Pathologies par chapitre"
description: "Liste les pathologies d'un chapitre CIM-10."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/reference/pathologies/chapter/{chapterCode}"
---

Cet endpoint retourne la liste des pathologies appartenant à un chapitre spécifique de la classification CIM-10, ainsi que la plage de codes couverte par ce chapitre. Les chapitres disponibles sont consultables via `GET /api/v1/reference/pathologies/chapters`.

## Scope requis

`reference.pathologies.view`

## Paramètre de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `chapterCode` | string | oui | Code du chapitre CIM-10 (ex. `I`, `J`, `A`). |

## Champs de réponse

La réponse contient les métadonnées du chapitre et un tableau `data` de `Pathology`.

### Métadonnées du chapitre

| Champ | Type | Description |
| --- | --- | --- |
| `chapter` | string | Code du chapitre en majuscules. |
| `chapter_label` | string | Libellé du chapitre. |
| `range` | string | Plage de codes CIM-10 couverte par le chapitre (ex. `I00-I99`). |
| `total` | integer | Nombre de pathologies dans le chapitre. |

### `Pathology`

| Champ | Type | Description |
| --- | --- | --- |
| `uid` | uuid | Identifiant public de la pathologie. |
| `icd10_code` | string | Code CIM-10 de la pathologie (ex. `I10`, `J45.0`). |
| `chapter_code` | string | Code du chapitre CIM-10 (ex. `I`, `J`). |
| `chapter_label` | string | Libellé du chapitre CIM-10. |
| `block_code` | string\|null | Code du bloc CIM-10. |
| `block_label` | string\|null | Libellé du bloc CIM-10. |
| `icd11_code` | string\|null | Code CIM-11 correspondant. |
| `icd11_entity_id` | string\|null | Identifiant d'entité CIM-11. |
| `label_fr` | string | Libellé en français de la pathologie. |
| `label_en` | string\|null | Libellé en anglais de la pathologie. |
| `is_billable` | boolean | Indique si la pathologie est facturable. |
| `is_active` | boolean | Indique si la pathologie est active dans le référentiel. |
| `synced_at` | string\|null | Date de dernière synchronisation (ISO 8601). |

```
GET /api/v1/reference/pathologies/chapter/I
```

## Erreurs

| Code | Description |
| --- | --- |
| 401 | Clé API manquante ou invalide. |
| 403 | Scope `reference.pathologies.view` manquant. |
