---
title: "Détail d'une consultation"
description: "Récupère le détail d'une consultation."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/encounters/{encounterId}"
---

Cet endpoint retourne le détail complet d'une consultation, incluant les actes médicaux, les ordonnances et les documents rattachés. Utilisez-le pour reconstituer le parcours clinique d'une consultation donnée.

## Scope requis

`clinical.encounters.view`

## Paramètres de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `encounterId` | string | Identifiant UUID de la consultation. |

## Réponse

La réponse contient les informations de la consultation (`encounter_type`, `encounter_date`, `chief_complaint`, `clinical_summary`) ainsi que les listes d'actes médicaux, d'ordonnances et de documents associées (chargées si disponibles).

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
