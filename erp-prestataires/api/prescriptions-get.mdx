---
title: "Consulter une prescription"
description: "Retourne le détail d'une prescription autorisée."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/prescriptions/{prescriptionUid}"
---

Cet endpoint retourne le détail complet d'une ordonnance : type, prescripteur, lignes de prescription, notes cliniques et statut.

## Scope requis

`clinical.prescriptions.view`

## Paramètres de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `prescriptionUid` | string | Identifiant UUID de l'ordonnance. |

## Accès après consentement

Pour les ordonnances accessibles hors consultation (dispensation en pharmacie, laboratoire), un consentement fort est requis. Récupérez d'abord un `consent_ref` via `/consent-requests` puis utilisez `GET /api/v1/covered-persons/{type}/{uid}/prescriptions` avec le `consent_ref` pour lister les ordonnances autorisées.

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
