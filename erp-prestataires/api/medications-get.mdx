---
title: "Fiche médicament"
description: "Récupère le détail d'un médicament du référentiel."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/reference/medications/{uid}"
---

Cet endpoint retourne la fiche complète d'un produit médicament du référentiel pivot Azurance, incluant les présentations et les mappings cliniques (ATC, RxCUI) lorsqu'ils sont disponibles.

## Scope requis

`reference.medications.view`

## Paramètres de chemin

| Paramètre | Type | Description |
| --- | --- | --- |
| `uid` | uuid | Identifiant public du produit médicament. |

## Paramètres de requête

| Paramètre | Type | Défaut | Description |
| --- | --- | --- | --- |
| `include_presentations` | boolean | `true` | Inclut les présentations (formes, dosages, conditionnements). |
| `include_mappings` | boolean | `true` | Inclut les mappings cliniques ATC/RxCUI. |

## Champs de réponse (`MedicationProduct`)

| Champ | Type | Description |
| --- | --- | --- |
| `uid` | uuid | Identifiant public du produit médicament. |
| `country_code` | string | Pays du référentiel produit. |
| `market_status` | string | Statut commercial (`LOCAL_AUTHORIZED`, `CANDIDATE`, `UNVERIFIED`, `WITHDRAWN`, `REJECTED`). |
| `source` | string | Source d'import (`ABMED_BENIN`, `BDPM_FR`, `MEDICAMENTS_API_FR`, `CSV`). |
| `source_details` | object | Détails de la source (`code`, `label`, `confidence`). |
| `designation` | string | Désignation officielle ou importée du produit. |
| `display_name` | string | Nom d'affichage. |
| `dci_raw` | string | DCI/substances. |
| `inn_name` | string | Dénomination commune internationale. |
| `marketing_authorization_holder` | string | Titulaire de l'AMM. |
| `origin_country` | string | Pays d'origine. |
| `public_price` | number | Prix public. |
| `authorization_number` | string | Numéro AMM. |
| `authorization_expires_at` | date | Date d'expiration de l'autorisation. |
| `source_url` | string | URL source. |
| `is_active` | boolean | Produit actif. |
| `presentations` | array | Présentations (formes, dosages, conditionnements). |
| `clinical_mapping` | object | Mapping clinique ATC/RxCUI principal. |
| `mappings` | array | Mappings cliniques complets. |
