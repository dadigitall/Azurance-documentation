title: "Rechercher des actes médicaux"
description: "Recherche des actes médicaux par mot-clé et catégorie."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/reference/medical-acts/search"
---

Cet endpoint permet de rechercher des actes médicaux dans le référentiel à partir d'un mot-clé. La recherche peut être filtrée par catégorie.

## Scope requis

`reference.medications.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `q` | string | oui | Terme de recherche. |
| `limit` | integer | non | Nombre max de résultats (min 1, max 100). |
| `category` | string | non | Filtrer par catégorie (voir la liste des catégories). |

## Catégories acceptées

`consultation`, `surgery`, `imaging`, `biology`, `anesthesia`, `physiotherapy`, `nursing`, `vaccination`, `medication_administration`, `mental_health`, `prevention`, `other`

## Exemple de requête

```bash
curl --request GET \
  --url "https://provider-api-sandbox.elenami.com/api/v1/reference/medical-acts/search?q=consultation&limit=10" \
  --header "X-Api-Key: $AZURANCE_PROVIDER_API_KEY"
```

## Exemple de réponse

```json
{
  "data": [
    {
      "code": "CS-001",
      "label": "Consultation générale",
      "category": "consultation"
    },
    {
      "code": "CS-002",
      "label": "Consultation spécialisée cardiologie",
      "category": "consultation"
    }
  ],
  "meta": {
    "total": 2
  }
}
```

## Erreurs

| Code | Description |
| --- | --- |
| 400 | Paramètre `q` manquant ou invalide. |
| 401 | Clé API manquante ou invalide. |
