---
title: "Lister les consultations"
description: "Liste les consultations du prestataire."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/encounters"
---

Cet endpoint retourne l'historique des consultations d'un assuré, filtré par le prestataire authentifié. Le paramètre `insured_uid` est obligatoire pour limiter les résultats à un assuré donné.

## Scope requis

`clinical.encounters.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `insured_uid` | uuid | oui | Identifiant de l'assuré. |
| `page` | integer | non | Numéro de page (pagination). |
| `per_page` | integer | non | Nombre de résultats par page. |

## Réponse

La réponse contient une liste paginée de consultations, triées par date décroissante. Chaque entrée inclut le type, la date, le motif et les relations chargées (`medical_acts`, `prescriptions`, `documents`) si disponibles.

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
