---
title: "Lister les prestations effectuées"
description: "Liste les prestations du prestataire lié à la clé API."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/service-executions"
---

Cet endpoint liste les prestations enregistrées par le prestataire authentifié. Utilisez-le pour suivre les prestations avant soumission de claim ou pour audit.

## Scope requis

`service_executions.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `page` | integer | non | Numéro de page. |
| `per_page` | integer | non | Résultats par page. |

## Réponse

La réponse contient une liste paginée des prestations enregistrées. Chaque entrée inclut la date, la personne couverte, le type de couverture, le statut et l'identifiant de prestation à référencer dans un claim.
