---
title: "Rechercher des pathologies"
description: "Recherche des pathologies par mot-clé et chapitre."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/reference/pathologies/search"
---

Cet endpoint permet de rechercher des pathologies dans le référentiel CIM-10 à partir d'un mot-clé. La recherche peut être filtrée par chapitre.

## Scope requis

`reference.pathologies.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `q` | string | oui | Terme de recherche. |
| `limit` | integer | non | Nombre max de résultats (min 1, max 100). |
| `chapter` | string | non | Filtrer par chapitre CIM-10 (ex. `IX`). |

## Exemple de requête

```bash
curl --request GET \
  --url "https://provider-api-sandbox.elenami.com/api/v1/reference/pathologies/search?q=hypertension&limit=10" \
  --header "X-Api-Key: $AZURANCE_PROVIDER_API_KEY"
```

## Exemple de réponse

```json
{
  "data": [
    {
      "code": "I10",
      "label": "Hypertension essentielle (primitive)",
      "chapter": "IX"
    },
    {
      "code": "I11",
      "label": "Cardiopathie hypertensive",
      "chapter": "IX"
    }
  ],
  "meta": {
    "total": 2
  }
}
```

## Erreurs

| Code | Description |
| --- | --- |
| 400 | Paramètre `q` manquant ou invalide. |
| 401 | Clé API manquante ou invalide. |
