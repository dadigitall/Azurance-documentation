---
title: "Prescriptions d'un assuré"
description: "Liste les prescriptions d'un assuré."
openapi: "/openapi/provider-api.openapi.yml GET /api/v1/insured/{insuredUid}/prescriptions"
---

Cet endpoint retourne l'historique complet des ordonnances d'un assuré, toutes consultations confondues. Il est utile pour reconstituer le parcours de soins ou vérifier les traitements en cours avant une nouvelle consultation.

## Scope requis

`clinical.prescriptions.view`

## Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `insuredUid` | string | oui | Identifiant UUID de l'assuré (path). |
| `page` | integer | non | Numéro de page. |
| `per_page` | integer | non | Résultats par page. |

## Réponse

La réponse contient une liste paginée d'ordonnances triées par date d'émission décroissante. Chaque entrée inclut le type, le prescripteur, la date d'émission et le statut.

## Chiffrement

Les réponses de cet endpoint sont chiffrées via JWE. Récupérez la clé publique RSA via `GET /api/v1/auth/encryption-key` pour déchiffrer la réponse.
