---
title: "Consulter une souscription"
description: "Retourne le détail d'un contrat."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/subscriptions/{subscriptionId}"
---

Cet endpoint retourne le détail complet d'une souscription : plan rattaché, période de couverture, statut et bénéficiaires associés.

## Scope requis

`insurer.members.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `subscriptionId` | string | oui | Identifiant de la souscription. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant de la souscription. |
| `policyholder_uuid` | string | Identifiant de l'assuré. |
| `subscription_number` | string | Numéro de souscription. |
| `plan_code` | string | Code du plan. |
| `plan_name` | string | Nom du plan. |
| `status` | string | Statut (`ACTIVE`, `SUSPENDED`, `EXPIRED`, `CANCELLED`). |
| `effective_date` | string | Date de début de couverture. |
| `expiry_date` | string | Date de fin de couverture. |
| `premium_amount` | number | Montant de la prime. |
| `premium_frequency` | string | Fréquence de prime. |
| `annual_coverage_limit` | number | Plafond annuel. |
| `annual_used_amount` | number | Consommation annuelle. |
| `remaining_coverage` | number | Couverture restante. |
| `policyholder` | object | Détail de l'assuré. |
| `beneficiaries` | array | Bénéficiaires rattachés. |
| `status_histories` | array | Historique des changements de statut. |
| `created_at` | string | Date de création. |
| `updated_at` | string | Date de dernière mise à jour. |

## Cas d'usage

- Afficher le détail d'un contrat dans un back-office.
- Vérifier la période de couverture avant un contrôle d'éligibilité.
- Consulter le statut avant une opération de renouvellement ou de suspension.

## Bonnes pratiques

Cet endpoint est lecture seule et n'a pas d'effet de bord. Utilisez-le librement pour afficher les fiches contrats, mais mettez en cache le résultat courte durée pour limiter les appels répétés.
