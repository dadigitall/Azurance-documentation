---
title: "Lister les préautorisations"
description: "Liste les demandes de préautorisation à traiter par la compagnie d'assurance."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/prior-authorizations"
---

Cet endpoint liste les demandes de préautorisation reçues par l'assureur. L'assureur et le tenant sont déduits automatiquement de `X-Api-Key` : aucun contexte explicite n'est requis.

## Scope requis

`insurer.prior_authorizations.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `status` | string | non | Filtrer par statut (`PENDING_REVIEW`, `INFO_NEEDED`, `APPROVED`, `REJECTED`, `EXPIRED`, `CANCELLED`, `CONSUMED`). |
| `provider_uuid` | uuid | non | Filtrer par prestataire demandeur. |
| `subscription_uid` | string | non | Filtrer par souscription. |
| `covered_person_uid` | string | non | Filtrer par personne couverte. |
| `page` | integer | non | Numéro de page. |
| `per_page` | integer | non | Taille de page, 20 par défaut. |

## Réponse

La réponse contient une liste paginée de préautorisations.

| Champ | Type | Description |
| --- | --- | --- |
| `data` | array | Préautorisations retournées. |
| `data[].uuid` | uuid | Identifiant public de la préautorisation. |
| `data[].status` | string | Statut de traitement. |
| `data[].priority` | string | Priorité (`URGENT`, `STANDARD`, `DEFERRED`). |
| `data[].provider_uuid` | string | Prestataire demandeur. |
| `data[].subscription_uid` | string | Souscription concernée. |
| `data[].covered_person_uid` | string | Personne couverte concernée. |
| `data[].coverage_type_code` | string | Code de garantie demandé. |
| `data[].estimated_amount` | number | Montant estimé. |
| `data[].authorized_amount` | number\|null | Montant autorisé après décision. |
| `meta` | object | Métadonnées de pagination. |
