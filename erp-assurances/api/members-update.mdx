---
title: "Mettre à jour un assuré"
description: "Met à jour les informations d'un membre."
openapi: "/openapi/insurer-api.openapi.yml PUT /api/v1/members/{memberId}"
---

Cet endpoint met à jour les informations administratives et de contact d'un assuré existant. La mise à jour est globale : envoyez l'ensemble des champs modifiables.

## Scope requis

`insurer.members.manage`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `memberId` | string | oui | Identifiant du membre. |

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `first_name` | string | oui | Prénom. |
| `last_name` | string | oui | Nom. |
| `date_of_birth` | string | oui | Date de naissance au format `YYYY-MM-DD`. |
| `gender` | string | non | Sexe (`MALE`, `FEMALE`, `OTHER`). |
| `email` | string | non | Adresse e-mail. |
| `phone_primary` | string | non | Numéro de téléphone principal. |
| `national_id` | string | non | Identifiant national. |
| `address` | string | non | Adresse postale. |
| `city` | string | non | Ville. |
| `country` | string | non | Pays. |
| `status` | string | non | Statut (`ACTIVE`, `INACTIVE`). |

## Cas d'usage

- Corriger une erreur de saisie lors de la création.
- Mettre à jour les coordonnées après un déménagement.
- Désactiver un assuré en passant le statut à `inactive`.

## Bonnes pratiques

La méthode `PUT` remplace l'ensemble des champs modifiables : récupérez d'abord le membre avec `members-get`, modifiez les champs nécessaires, puis renvoyez l'objet complet pour éviter d'écraser des valeurs par omission.
