title: "Détail d'une facture"
description: "Récupère le détail d'une facture à payer."

---

Cet endpoint récupère le détail d'une facture à payer : prestataire émetteur, montant, statut et échéance.

## Scope requis

`insurer.billing.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uuid` | string | oui | Identifiant unique de la facture. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant unique de la facture. |
| `invoice_number` | string | Numéro de facture. |
| `beneficiary_type` | string | Type de bénéficiaire (`PROVIDER`). |
| `beneficiary_uuid` | string | Identifiant du prestataire émetteur. |
| `beneficiary_name` | string | Nom du prestataire. |
| `provider_uuid` | string | Identifiant du prestataire. |
| `provider_name` | string | Nom du prestataire. |
| `status` | string | Statut (`ISSUED`, `PAID`, `DISPUTED`). |
| `total_amount` | number | Montant total. |
| `paid_amount` | number | Montant déjà réglé. |
| `remaining_amount` | number | Reste à régler. |
| `currency` | string | Devise. |
| `period_start` | string | Début de période facturée. |
| `period_end` | string | Fin de période facturée. |
| `issued_at` | string | Date d'émission au format ISO 8601. |
| `items` | array | Lignes de la facture (voir `billing-payable-invoice-items`). |

## Cas d'usage

- Afficher le détail d'une facture avant validation d'un paiement.
- Vérifier le statut d'une facture en litige.
- Contrôler le montant déjà réglé sur une facture partiellement payée.

## Bonnes pratiques

Pour consulter les lignes détaillées de la facture, utilisez `billing-payable-invoice-items`. Pour enregistrer un règlement, utilisez `billing-payment-create` avec une allocation sur cette facture.
