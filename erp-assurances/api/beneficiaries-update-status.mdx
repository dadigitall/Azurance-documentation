description: "Met à jour le statut d'un bénéficiaire rattaché à une souscription."
openapi: "/openapi/insurer-api.openapi.yml PATCH /api/v1/subscriptions/{subscriptionId}/beneficiaries/{beneficiaryId}/status"
---

Cet endpoint modifie le statut d'un bénéficiaire rattaché à une souscription. Utilisez-le pour activer ou désactiver un ayant droit sans le supprimer.

## Scope requis

`insurer.members.manage`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `subscriptionId` | string | oui | Identifiant de la souscription. |
| `beneficiaryId` | string | oui | Identifiant du bénéficiaire. |

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `status` | string | oui | Statut cible (`ACTIVE`, `INACTIVE`). |
| `reason` | string | non | Motif du changement de statut. |

## Cas d'usage

- Désactiver un bénéficiaire ayant atteint l'âge limite de couverture.
- Réactiver un bénéficiaire suite à une erreur de saisie.
- Suspendre un bénéficiaire en attente de vérification documentaire.

## Bonnes pratiques

Fournissez un `reason` pour la traçabilité. Préférez la désactivation à la suppression : un bénéficiaire inactif conserve son historique et peut être réactivé ultérieurement.
