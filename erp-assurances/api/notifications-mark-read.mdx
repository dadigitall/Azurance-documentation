---
title: "Marquer comme lu"
description: "Marque une notification comme lue."
openapi: "/openapi/insurer-api.openapi.yml PATCH /api/v1/notifications/{id}/read"
---

Cet endpoint marque une notification comme lue. Il met à jour le statut de lecture et enregistre la date de lecture lorsque le service de notification la retourne.

## Scope requis

`insurer.notifications.manage`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `id` | string | oui | Identifiant de la notification. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data.id` | integer | Identifiant de la notification. |
| `data.uid` | string | Identifiant public. |
| `data.status` | string | Statut d'envoi. |
| `data.read_at` | string\|null | Date de lecture au format ISO 8601. |
| `data.updated_at` | string | Date de mise à jour au format ISO 8601. |

## Cas d'usage

- Marquer une notification comme lue après consultation.
- Synchroniser le statut de lecture entre un back-office et l'API.
- Nettoyer la liste des notifications non lues.

## Bonnes pratiques

L'appel est idempotent si le service de notification accepte une notification déjà lue. Appelez cet endpoint après affichage du détail pour maintenir le compteur de notifications non lues à jour.
