---
title: "Consulter un assuré"
description: "Retourne le détail d'un membre du portefeuille."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/members/{memberId}"
---

Cet endpoint retourne le détail complet d'un assuré : informations administratives, coordonnées et statut.

## Scope requis

`insurer.members.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `memberId` | string | oui | Identifiant du membre. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant du membre. |
| `policy_number` | string | Numéro de police. |
| `identity_uid` | string | Identifiant d'identité. |
| `national_id` | string | Identifiant national. |
| `first_name` | string | Prénom. |
| `last_name` | string | Nom. |
| `full_name` | string | Nom complet. |
| `date_of_birth` | string | Date de naissance. |
| `gender` | string | Sexe. |
| `phone_primary` | string | Téléphone principal. |
| `email` | string | Adresse e-mail. |
| `address` | string | Adresse postale. |
| `city` | string | Ville. |
| `country` | string | Pays. |
| `status` | string | Statut (`ACTIVE`, `INACTIVE`). |
| `kyc_status` | string | Statut KYC. |
| `subscriptions` | array | Souscriptions rattachées. |
| `created_at` | string | Date de création. |
| `updated_at` | string | Date de dernière mise à jour. |

## Cas d'usage

- Afficher la fiche détaillée d'un assuré dans un back-office.
- Récupérer les coordonnées avant un envoi postal.
- Vérifier le statut avant une opération de souscription.

## Bonnes pratiques

Cet endpoint expose des données personnelles : ne journalisez pas la réponse complète. Préférez stocker l'identifiant et ne récupérer le détail qu'à l'affichage.
