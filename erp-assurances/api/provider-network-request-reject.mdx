---
title: "Rejeter une demande d'adhésion réseau"
description: "Rejette une demande d'adhésion au réseau prestataire avec un motif optionnel."
openapi: "/openapi/insurer-api.openapi.yml PATCH /api/v1/providers/network-requests/{uid}/reject"
---

Cet endpoint rejette une demande d'adhésion réseau en statut `PENDING`. Le motif optionnel est enregistré dans `rejected_reason` et peut être affiché au prestataire dans le suivi de ses relations réseau.

## Scope requis

`insurer.providers.manage`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uid` | uuid | oui | Identifiant public de la demande/relation réseau (`relationship_uid`). |

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `reason` | string | non | Motif de rejet (max 512 caractères). |

## Bonnes pratiques

- Utilisez un motif clair et actionnable, par exemple une pièce manquante ou une exigence réseau non satisfaite.
- Ne mettez pas de données sensibles ou de commentaire interne dans `reason` : ce champ peut être rendu visible au prestataire.
- Si la demande doit être complétée plutôt que refusée, rejetez avec un motif indiquant les éléments à fournir.

## Exemple de requête

```json
{
  "reason": "Dossier administratif incomplet. Merci de transmettre l'autorisation d'exercice et le RIB établissement."
}
```

## Réponse

La réponse retourne la relation réseau mise à jour. Le statut est `rejected` dans la réponse brute de l'organization-service.

| Champ | Type | Description |
| --- | --- | --- |
| `data.uid` | uuid | Identifiant public de la relation. |
| `data.source_uid` | uuid | UID de l'organisation assureur. |
| `data.target_uid` | uuid | UID de l'organisation prestataire. |
| `data.type` | string | Type de relation (`care_network`). |
| `data.status` | string | Statut interne (`rejected`). |
| `data.initiated_by` | string\|null | Origine de la demande. |
| `data.rejected_reason` | string\|null | Motif de rejet enregistré. |
| `data.starts_at` | string\|null | Date de début si configurée. |
| `data.ends_at` | string\|null | Date de fin si configurée. |
| `data.metadata` | object | Métadonnées conservées de la demande. |
| `data.created_at` | date-time | Date de création de la demande. |
| `data.updated_at` | date-time | Date de rejet. |

## Erreurs fréquentes

| Statut | Cause |
| --- | --- |
| `404` | La demande n'existe pas. |
| `422` | La demande n'est plus en statut `pending` et ne peut pas être rejetée. |
