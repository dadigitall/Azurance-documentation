---
title: "Décider une préautorisation"
description: "Approuve, rejette ou demande des informations complémentaires sur une préautorisation."
openapi: "/openapi/insurer-api.openapi.yml POST /api/v1/prior-authorizations/{uid}/decision"
---

Cet endpoint enregistre la décision de l'assureur sur une demande de préautorisation. Une décision `APPROVED` peut créer une réservation souple de plafond ; une décision `REJECTED` ou `INFO_NEEDED` doit expliquer la raison métier.

## Scope requis

`insurer.prior_authorizations.view`

L'API exige le scope `insurer.prior_authorizations.view` pour ce chemin, y compris pour l'action de décision.

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uid` | uuid | oui | Identifiant public de la préautorisation. |

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `decision` | string | oui | Décision (`APPROVED`, `REJECTED`, `INFO_NEEDED`). |
| `decided_by` | string | oui | Identifiant ou rôle de l'opérateur ayant décidé. |
| `authorized_amount` | number | non | Montant autorisé. Requis pour `APPROVED`. |
| `expires_at` | string | non | Date d'expiration de l'accord, au format ISO 8601. |
| `reason` | string | non | Motif métier. Requis pour `REJECTED` ou `INFO_NEEDED`. |
| `notes` | string | non | Notes de décision. |
| `conditions` | array | non | Conditions associées à l'accord. |
| `metadata` | object | non | Métadonnées libres. |

## Exemple de requête

```json
{
  "decision": "APPROVED",
  "decided_by": "medical_advisor",
  "authorized_amount": 150000,
  "expires_at": "2026-08-30T23:59:59Z",
  "notes": "Accord donné après revue médicale.",
  "conditions": [
    "Facturation conforme au proforma validé"
  ],
  "metadata": {
    "decision_channel": "insurer_api"
  }
}
```

## Erreurs fréquentes

| Statut | Cause |
| --- | --- |
| `404` | Aucune préautorisation avec cet identifiant pour le tenant de la clé API. |
| `422` | Montant autorisé manquant pour une approbation, motif manquant pour un rejet/demande d'information, ou transition invalide. |
| `503` | Service externe indisponible pour la réservation ou le contrôle de plafond. |
