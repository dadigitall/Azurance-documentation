---
title: "Détail d'un paiement"

---

Cet endpoint récupère le détail d'un paiement : montant, moyen de paiement, bénéficiaire et statut.

## Scope requis

`insurer.billing.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uuid` | string | oui | Identifiant unique du paiement. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant unique du paiement. |
| `payment_number` | string | Numéro du paiement. |
| `beneficiary_type` | string | Type de bénéficiaire. |
| `beneficiary_uuid` | string | Identifiant du bénéficiaire. |
| `beneficiary_name` | string | Nom du bénéficiaire. |
| `payment_method` | string | Moyen de paiement. |
| `payment_provider` | string | Fournisseur de paiement. |
| `status` | string | Statut (`CREATED`, `PROCESSING`, `SUCCEEDED`, `FAILED`). |
| `amount` | number | Montant total. |
| `allocated_amount` | number | Montant alloué. |
| `currency` | string | Devise. |
| `external_reference` | string | Référence bancaire. |
| `requested_by` | string | Auteur de la demande. |
| `requested_at` | string | Date de demande. |
| `succeeded_at` | string | Date de succès, présente si `SUCCEEDED`. |
| `allocations` | array | Répartitions du paiement sur les factures. |

## Cas d'usage

- Afficher le détail d'un paiement dans un back-office comptable.
- Vérifier le statut avant une relance.
- Contrôler les métadonnées associées au règlement.

## Bonnes pratiques

Pour consulter la répartition du paiement sur les factures, utilisez `billing-payment-allocations`. Pour confirmer un paiement en statut `pending`, utilisez `billing-payment-confirm`.
