---
title: "Lister les souscriptions"
description: "Retourne les contrats visibles par la clé API assurance."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/subscriptions"
---

Cet endpoint retourne la liste paginée des souscriptions (contrats) visibles par la clé API. Utilisez-le pour synchroniser votre référentiel contracts ou alimenter un écran de gestion.

## Scope requis

`insurer.members.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `page` | integer | non | Numéro de page. Défaut : `1`. |
| `per_page` | integer | non | Nombre d'éléments par page. Défaut : `20`. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data` | array | Liste des souscriptions. |
| `data[].uuid` | string | Identifiant de la souscription. |
| `data[].policyholder_uuid` | string | Identifiant de l'assuré. |
| `data[].subscription_number` | string | Numéro de souscription. |
| `data[].plan_code` | string | Code du plan. |
| `data[].plan_name` | string | Nom du plan. |
| `data[].status` | string | Statut (`ACTIVE`, `SUSPENDED`, `EXPIRED`, `CANCELLED`). |
| `data[].effective_date` | string | Date de début de couverture. |
| `data[].expiry_date` | string | Date de fin de couverture. |
| `data[].premium_amount` | number | Montant de la prime. |
| `data[].remaining_coverage` | number | Couverture restante. |
| `meta` | object | Métadonnées de pagination. |

## Cas d'usage

- Synchroniser le référentiel contrats vers un SI tiers.
- Lister les contrats actifs pour un tableau de bord.
- Identifier les contrats arrivant à échéance pour anticiper le renouvellement.

## Bonnes pratiques

Pour suivre les changements de statut en temps réel, abonnez-vous aux webhooks souscription plutôt que de scruter cette liste en continu.
