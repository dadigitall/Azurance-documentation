---
title: "Consulter un claim"
description: "Retourne le détail d'un claim."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/claims/{claimId}"
---

Cet endpoint retourne le détail complet d'un claim : prestataire, souscription, actes facturés, statut et décision.

## Scope requis

`insurer.claims.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `claimId` | string | oui | Identifiant du claim. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant public du claim. |
| `claim_number` | string | Numéro du claim. |
| `subscription_id` | string | Identifiant de la souscription. |
| `policyholder_id` | string | Identifiant de l'assuré. |
| `provider_uuid` | string | Identifiant du prestataire. |
| `provider_name` | string | Nom du prestataire. |
| `covered_person_type` | string | `POLICYHOLDER` ou `BENEFICIARY`. |
| `covered_person_uid` | string | Identifiant de la personne couverte. |
| `coverage_type_code` | string | Code de garantie. |
| `consent_ref` | string | Référence de consentement. |
| `status` | string | Statut (`SUBMITTED`, `UNDER_REVIEW`, `APPROVED`, `REJECTED`, `PAID`). |
| `amount_claimed` | number | Montant réclamé. |
| `amount_approved` | number | Montant approuvé, présent si `APPROVED` ou `PAID`. |
| `amount_paid` | number | Montant payé, présent si `PAID`. |
| `currency` | string | Devise. |
| `service_date` | string | Date de prestation. |
| `submitted_at` | string | Date de soumission. |
| `reviewed_at` | string | Date de revue, présente si statut avancé. |
| `paid_at` | string | Date de paiement, présente si `PAID`. |
| `rejection_reason` | string | Motif de rejet, présent si `REJECTED`. |
| `reviewed_by` | string | Opérateur ayant pris la décision. |
| `documents` | array | Pièces justificatives rattachées. |
| `items` | array | Lignes de prestation du claim. |
| `latest_history` | object | Dernier changement de statut. |

## Cas d'usage

- Afficher le détail d'un claim dans un écran de décision.
- Vérifier les actes facturés avant validation.
- Consulter le motif de rejet pour informer le prestataire.

## Bonnes pratiques

Cet endpoint est lecture seule. Pour consulter les pièces justificatives, utilisez `claim-documents-list`. Pour modifier le statut, utilisez `claims-update-status`.
