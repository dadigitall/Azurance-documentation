---
title: "Renouveler une souscription"
description: "Crée une nouvelle période contractuelle à partir d'une souscription existante."
openapi: "/openapi/insurer-api.openapi.yml POST /api/v1/subscriptions/{subscriptionId}/renew"
---

Cet endpoint crée une nouvelle période contractuelle à partir d'une souscription existante. Le contrat initial est clôturé et un nouveau contrat reprenant les mêmes paramètres est ouvert pour la période suivante.

## Scope requis

`insurer.members.manage`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `subscriptionId` | string | oui | Identifiant de la souscription à renouveler. |

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `effective_date` | string | non | Date de début de la nouvelle période. Défaut : lendemain de la fin précédente. |
| `expiry_date` | string | non | Date de fin de la nouvelle période. Déduite du plan si absent. |
| `plan_code` | string | non | Nouveau plan si changement lors du renouvellement. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant de la nouvelle souscription. |
| `policyholder_uuid` | string | Identifiant de l'assuré. |
| `subscription_number` | string | Numéro de souscription. |
| `plan_code` | string | Code du plan. |
| `status` | string | Statut initial (`ACTIVE`). |
| `effective_date` | string | Date de début effective. |
| `expiry_date` | string | Date de fin effective. |
| `renewed_from_uuid` | string | Identifiant du contrat clôturé. |
| `premium_amount` | number | Montant de la prime. |
| `remaining_coverage` | number | Couverture restante. |
| `created_at` | string | Date de création au format ISO 8601. |

## Cas d'usage

- Renouveler automatiquement un contrat arrivant à échéance.
- Changer de plan lors du renouvellement annuel.
- Prolonger un contrat suite à un avenant commercial.

## Bonnes pratiques

Lancez le renouvellement avant la date de fin pour garantir la continuité de couverture. Fournissez un `Idempotency-Key` pour éviter la création de doublons en cas de retry.
