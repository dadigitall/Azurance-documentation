---
title: "Évaluation de fraude par UUID"
description: "Récupère une évaluation de fraude par son identifiant."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/fraud-assessments/{uuid}"
---

Cet endpoint récupère une évaluation de fraude par son identifiant unique. Contrairement à `fraud-assessment-get` qui retourne la dernière évaluation d'un claim, cet endpoint cible une évaluation précise.

## Scope requis

`insurer.claims.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uuid` | string | oui | Identifiant unique de l'évaluation. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant unique de l'évaluation. |
| `claim_uuid` | string | Identifiant du claim évalué. |
| `provider_uuid` | string | Identifiant du prestataire. |
| `status` | string | Statut (`PENDING`, `IN_REVIEW`, `COMPLETED`). |
| `risk_score` | number | Score de risque, présent si `COMPLETED`. |
| `risk_level` | string | Niveau de risque (`LOW`, `MEDIUM`, `HIGH`), présent si `COMPLETED`. |
| `recommended_action` | string | Action recommandée (`APPROVE`, `REVIEW`, `REJECT`). |
| `trigger` | string | Origine du déclenchement. |
| `priority` | string | Priorité d'analyse. |
| `flags` | array | Indicateurs ayant contribué au score. |
| `ai_runs` | array | Exécutions d'agents IA ayant participé à l'évaluation. |
| `completed_at` | string | Date de complétion, présente si `COMPLETED`. |
| `created_at` | string | Date de création. |

## Cas d'usage

- Consulter une évaluation archivée sans repartir du claim.
- Partager un lien direct vers une évaluation entre opérateurs.
- Vérifier le résultat d'une évaluation après un feedback.

## Bonnes pratiques

Conservez l'`uuid` retourné à la création pour pouvoir interroger l'évaluation ultérieurement. Si vous ne disposez que du `claimId`, utilisez `fraud-assessment-get` pour récupérer la dernière évaluation.
