---
title: "Lister les paiements"
description: "Liste les paiements effectués par l'assureur."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/billing/payments"
---

Cet endpoint liste les paiements effectués par l'assureur. Utilisez-le pour suivre les règlements et alimenter la comptabilité.

## Scope requis

`insurer.billing.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `page` | integer | non | Numéro de page. Défaut : `1`. |
| `per_page` | integer | non | Nombre d'éléments par page. Défaut : `20`. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data` | array | Liste des paiements. |
| `data[].uuid` | string | Identifiant unique du paiement. |
| `data[].payment_number` | string | Numéro du paiement. |
| `data[].beneficiary_type` | string | Type de bénéficiaire. |
| `data[].beneficiary_uuid` | string | Identifiant du bénéficiaire. |
| `data[].beneficiary_name` | string | Nom du bénéficiaire. |
| `data[].payment_method` | string | Moyen de paiement. |
| `data[].status` | string | Statut (`CREATED`, `PROCESSING`, `SUCCEEDED`, `FAILED`). |
| `data[].amount` | number | Montant total. |
| `data[].allocated_amount` | number | Montant alloué. |
| `data[].currency` | string | Devise. |
| `data[].external_reference` | string | Référence bancaire. |
| `data[].requested_at` | string | Date de demande. |
| `data[].succeeded_at` | string | Date de succès, présente si `SUCCEEDED`. |
| `data[].allocations` | array | Répartitions du paiement. |
| `meta` | object | Métadonnées de pagination. |

## Cas d'usage

- Suivre les règlements effectués sur une période.
- Alimenter la comptabilité fournisseurs.
- Identifier les paiements en statut `pending` à confirmer.

## Bonnes pratiques

Pour le détail d'un paiement, utilisez `billing-payment-get`. Pour consulter sa répartition sur les factures, utilisez `billing-payment-allocations`. Pour un suivi incrémental, utilisez `billing-sync`.
