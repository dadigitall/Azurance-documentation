---
title: "Créer un assuré"
description: "Crée un membre dans le portefeuille de l'assureur."
openapi: "/openapi/insurer-api.openapi.yml POST /api/v1/members"
---

Cet endpoint crée un nouvel assuré dans le portefeuille de l'assureur. Le membre créé peut ensuite être rattaché à une souscription.

## Scope requis

`insurer.members.manage`

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `external_id` | string | oui | Référence externe unique (votre identifiant métier). |
| `first_name` | string | oui | Prénom. |
| `last_name` | string | oui | Nom. |
| `date_of_birth` | string | oui | Date de naissance au format `YYYY-MM-DD`. |
| `gender` | string | non | Sexe (`male`, `female`, `other`). |
| `email` | string | non | Adresse e-mail. |
| `phone` | string | non | Numéro de téléphone. |
| `national_id` | string | non | Identifiant national. |
| `address` | object | non | Adresse postale. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant du membre créé. |
| `policy_number` | string | Numéro de police. |
| `identity_uid` | string | Identifiant d'identité. |
| `national_id` | string | Identifiant national. |
| `first_name` | string | Prénom. |
| `last_name` | string | Nom. |
| `full_name` | string | Nom complet. |
| `date_of_birth` | string | Date de naissance. |
| `gender` | string | Sexe. |
| `phone_primary` | string | Téléphone principal. |
| `email` | string | Adresse e-mail. |
| `status` | string | Statut initial (`ACTIVE`). |
| `kyc_status` | string | Statut KYC. |
| `registration_date` | string | Date d'enregistrement. |
| `created_at` | string | Date de création au format ISO 8601. |

## Cas d'usage

- Créer un assuré lors de l'onboarding d'un nouveau client.
- Importer un référentiel externe vers le portefeuille Azurance.
- Préparer un assuré avant la création de sa souscription.

## Bonnes pratiques

Fournissez un `external_id` stable et unique pour garantir l'idempotence métier. Ne créez pas un assuré déjà présent : recherchez-le d'abord avec `members-list` et son `external_id`.
