---
title: "Changer le statut d'une souscription"
description: "Suspend, réactive, expire ou annule une souscription selon les statuts autorisés."
openapi: "/openapi/insurer-api.openapi.yml PATCH /api/v1/subscriptions/{subscriptionId}/status"
---

Cet endpoint modifie le statut d'une souscription. Les transitions autorisées dépendent du statut courant et du statut cible.

## Scope requis

`insurer.members.manage`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `subscriptionId` | string | oui | Identifiant de la souscription. |

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `status` | string | oui | Statut cible (`SUSPENDED`, `ACTIVE`, `EXPIRED`, `CANCELLED`). |
| `reason` | string | non | Motif du changement de statut. |

## Transitions autorisées

| Statut courant | Statuts cibles possibles |
| --- | --- |
| `ACTIVE` | `SUSPENDED`, `EXPIRED`, `CANCELLED` |
| `SUSPENDED` | `ACTIVE`, `CANCELLED` |
| `EXPIRED` | `CANCELLED` |
| `CANCELLED` | aucune |

## Cas d'usage

- Suspendre un contrat en cas de non-paiement de cotisation.
- Réactiver un contrat suspendu après régularisation.
- Annuler un contrat suite à une résiliation demandée par l'assuré.

## Bonnes pratiques

Fournissez toujours un `reason` pour assurer la traçabilité. Vérifiez le statut courant avec `subscriptions-get` avant l'appel pour éviter une transition invalide et un rejet `409`.
