---
title: "Lister les livraisons webhook"
description: "Récupère l'historique des tentatives de livraison d'un abonnement webhook."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/webhooks/{uuid}/deliveries"
---

Cet endpoint retourne l'historique paginé des tentatives de livraison des événements webhook pour un abonnement donné. Utilisez-le pour auditer les livraisons, diagnostiquer les échecs et identifier les livraisons à relancer.

## Scope requis

`insurer.webhooks.view`

## Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uuid` (path) | string | oui | UUID de l'abonnement webhook. |
| `per_page` (query) | integer | non | Nombre de livraisons par page (1-100, défaut 20). |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data` | array | Liste des livraisons. |
| `data[].uuid` | string | Identifiant unique de la livraison. |
| `data[].event_id` | string | Identifiant unique de l'événement. Utiliser pour dédupliquer côté intégrateur. |
| `data[].event_type` | string | Type d'événement livré. |
| `data[].status` | string | Statut de la livraison (`PENDING`, `DELIVERED`, `FAILED`). |
| `data[].attempts` | integer | Nombre de tentatives effectuées. |
| `data[].response_status` | integer | Code HTTP de la dernière réponse (null si non tentée). |
| `data[].next_retry_at` | string | Date de la prochaine tentative (null si terminée). |
| `data[].delivered_at` | string | Date de livraison réussie (null sinon). |
| `data[].last_error` | string | Message d'erreur de la dernière tentative (null si réussie). |
| `meta` | object | Métadonnées de pagination. |

## Statuts de livraison

| Statut | Description |
| --- | --- |
| `PENDING` | Livraison en attente ou programmée pour retry. |
| `DELIVERED` | Livraison réussie (réponse 2xx reçue). |
| `FAILED` | Livraison définitivement échouée (4xx non 429, ou épuisement des retries). |

## Cas d'usage

- Diagnostiquer pourquoi un intégrateur ne reçoit pas certains événements.
- Identifier les livraisons échouées à relancer manuellement via `webhooks-deliveries-retry`.
- Auditer la fiabilité de livraison sur une période donnée.
