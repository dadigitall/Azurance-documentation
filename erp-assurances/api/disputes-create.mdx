---
title: "Déclarer un litige"
description: "Ouvre un litige à l'initiative de l'assureur."
openapi: "/openapi/insurer-api.openapi.yml POST /api/v1/disputes"
---

Cet endpoint permet à l'assureur de déclarer un litige — contre un prestataire (surfacturation, facture non conforme) ou tout autre acteur. Le tenant assureur (`opened_by_type = insurer`, `insurer_tenant_uid`) est **dérivé de la clé API** : il ne doit jamais être transmis dans le body.

## Scope requis

`insurer.disputes.manage`

## Champs du body

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `subject` | string | oui | Objet du litige (max 255 car.). |
| `description` | string | non | Détail du différend. |
| `amount` | number | non | Montant contesté en XOF (défaut : 0). |
| `category` | string | non | `refus_pec`, `tarification`, `delai_paiement`, `hors_contrat`, `autre`. |
| `priority` | string | non | `low`, `normal`, `high` (défaut : `normal`). |
| `counterparty_type` | string | non | Partie adverse : `insured`, `provider`, `insurer`. |
| `counterparty_uid` | string | non | UID de la partie adverse si connu. |
| `counterparty_name` | string | non | Nom de la partie adverse (affichage). |
| `provider_uuid` | string | non | `providers.uuid` du prestataire concerné (via le module réseau). |
| `provider_name` | string | non | Nom du prestataire (affichage). |
| `insured_uid` | string | non | Identité de l'assuré concerné, si applicable. |
| `subject_ref` | string | non | Référence de la prestation litigieuse : uuid d'un claim ou d'une exécution de service. |

## Comportement

- `opened_by_type` est fixé à `insurer` et `stage` à `instruction` côté serveur.
- Un identifiant métier `LIT-YYYY-NNNN` est généré et retourné dans `dispute.id`.
- Les litiges créés sont visibles dans la liste `GET /api/v1/disputes` et instruits par l'ASA.

## Exemple de requête

```bash
curl --request POST \
  --url "https://insurer-api-sandbox.elenami.com/api/v1/disputes" \
  --header "Content-Type: application/json" \
  --header "X-Api-Key: $AZURANCE_INSURER_API_KEY" \
  --header "X-Request-Id: req_sandbox_20261027_001" \
  --data '{
    "subject": "Surfacturation constatée sur la facture FAC-SANDBOX-088",
    "description": "Le tarif facturé dépasse de 40 % le barème conventionnel applicable à cet acte.",
    "amount": 142000,
    "category": "tarification",
    "priority": "normal",
    "counterparty_type": "provider",
    "counterparty_name": "Clinique du Plateau",
    "provider_name": "Clinique du Plateau",
    "subject_ref": "clm_sandbox_88f3"
  }'
```

## Erreurs

| Code | Description |
| --- | --- |
| 401 | Clé API manquante ou invalide. |
| 403 | Scope `insurer.disputes.manage` manquant. |
| 422 | Payload invalide (`subject` absent, `category` hors enum, `counterparty_type` hors enum). |
