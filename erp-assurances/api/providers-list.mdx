---
title: "Lister les prestataires"
description: "Retourne les prestataires visibles dans le réseau de l'assureur."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/providers"
---

Cet endpoint retourne la liste paginée des prestataires visibles dans le réseau de l'assureur. Utilisez-le pour synchroniser votre référentiel ou alimenter un écran de recherche.

## Scope requis

`insurer.providers.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `page` | integer | non | Numéro de page. Défaut : `1`. |
| `per_page` | integer | non | Nombre d'éléments par page. Défaut : `20`. |
| `type` | string | non | Filtre par type (`HOSPITAL`, `CLINIC`, `PHARMACY`, `LABORATORY`). |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data` | array | Liste des prestataires. |
| `data[].id` | integer | Identifiant interne. |
| `data[].uuid` | string | Identifiant public. |
| `data[].name` | string | Nom du prestataire. |
| `data[].type` | string | Type d'établissement. |
| `data[].status` | string | Statut (`ACTIVE`, `INACTIVE`). |
| `data[].tier` | string | Niveau de réseau. |
| `data[].accreditation_number` | string | Numéro d'accréditation. |
| `data[].phone` | string | Téléphone. |
| `data[].email` | string | E-mail. |
| `data[].city` | string | Ville. |
| `data[].country` | string | Pays. |
| `data[].specialties` | array | Spécialités. |
| `meta` | object | Métadonnées de pagination. |

## Cas d'usage

- Synchroniser le référentiel prestataires vers un SI tiers.
- Lister les établissements par type pour un annulaire réseau.
- Alimenter un sélecteur de prestataire dans un back-office.

## Bonnes pratiques

Utilisez le filtre `type` pour limiter le volume transféré. Pour vérifier l'appartenance réseau d'un prestataire précis, utilisez `provider-network-check`.
