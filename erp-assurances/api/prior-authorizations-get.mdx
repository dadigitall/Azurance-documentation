---
title: "Consulter une préautorisation"
description: "Retourne le détail d'une demande de préautorisation."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/prior-authorizations/{uid}"
---

Cet endpoint retourne le détail d'une préautorisation reçue par l'assureur : statut, personne couverte, garantie demandée, pièces, décision et informations de réservation de plafond.

## Scope requis

`insurer.prior_authorizations.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `uid` | uuid | oui | Identifiant public de la préautorisation. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data.uuid` | uuid | Identifiant public de la préautorisation. |
| `data.status` | string | Statut (`PENDING_REVIEW`, `INFO_NEEDED`, `APPROVED`, `REJECTED`, `EXPIRED`, `CANCELLED`, `CONSUMED`). |
| `data.priority` | string | Priorité (`URGENT`, `STANDARD`, `DEFERRED`). |
| `data.provider_uuid` | string | Prestataire demandeur. |
| `data.subscription_uid` | string | Souscription concernée. |
| `data.covered_person_type` | string | Type de personne couverte (`policyholder`, `beneficiary`). |
| `data.covered_person_uid` | string | Identifiant de la personne couverte. |
| `data.coverage_type_code` | string | Code de garantie demandé. |
| `data.estimated_amount` | number | Montant estimé. |
| `data.authorized_amount` | number\|null | Montant autorisé après approbation. |
| `data.reason` | string\|null | Motif de décision ou demande d'information. |
| `data.items` | array\|null | Lignes ou actes demandés. |
| `data.documents` | array\|null | Documents joints. |
| `data.limit_reservation_uid` | string\|null | Réservation de plafond créée à l'approbation. |
| `data.decision_snapshot` | object\|null | Trace de la décision. |
