Cet endpoint liste les factures à payer, c'est-à-dire les factures émises par les prestataires et en attente de règlement par l'assureur.

## Scope requis

`insurer.billing.view`

## Paramètres de requête

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `page` | integer | non | Numéro de page. Défaut : `1`. |
| `per_page` | integer | non | Nombre d'éléments par page. Défaut : `20`. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `data` | array | Liste des factures. |
| `data[].uuid` | string | Identifiant unique de la facture. |
| `data[].invoice_number` | string | Numéro de facture. |
| `data[].beneficiary_type` | string | Type de bénéficiaire (`PROVIDER`). |
| `data[].beneficiary_uuid` | string | Identifiant du prestataire. |
| `data[].beneficiary_name` | string | Nom du prestataire. |
| `data[].status` | string | Statut (`ISSUED`, `PAID`, `DISPUTED`). |
| `data[].total_amount` | number | Montant total. |
| `data[].paid_amount` | number | Montant réglé. |
| `data[].remaining_amount` | number | Reste à régler. |
| `data[].currency` | string | Devise. |
| `data[].period_start` | string | Début de période. |
| `data[].period_end` | string | Fin de période. |
| `data[].issued_at` | string | Date d'émission. |
| `meta` | object | Métadonnées de pagination (`next_cursor`). |

## Cas d'usage

- Lister les factures à régler pour le back-office comptable.
- Identifier les factures proches de l'échéance.
- Préparer un lot de paiements pour validation.

## Bonnes pratiques

Pour le détail d'une facture, utilisez `billing-payable-invoice-get`. Pour consulter les lignes, utilisez `billing-payable-invoice-items`. Pour un suivi incrémental des factures, utilisez `billing-sync`.
