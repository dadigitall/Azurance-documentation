---
title: "Détail d'une évaluation de fraude"
description: "Récupère l'évaluation de fraude d'un sinistre."
openapi: "/openapi/insurer-api.openapi.yml GET /api/v1/claims/{claimId}/fraud-assessment"
---

Cet endpoint récupère la dernière évaluation de fraude associée à un claim. Utilisez-le pour consulter le score de risque et le statut de l'analyse.

## Scope requis

`insurer.claims.view`

## Paramètres de chemin

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `claimId` | string | oui | Identifiant du claim. |

## Réponse

| Champ | Type | Description |
| --- | --- | --- |
| `uuid` | string | Identifiant unique de l'évaluation. |
| `claim_uuid` | string | Identifiant du claim. |
| `provider_uuid` | string | Identifiant du prestataire. |
| `status` | string | Statut (`PENDING`, `IN_REVIEW`, `COMPLETED`). |
| `risk_score` | number | Score de risque, présent si `COMPLETED`. |
| `risk_level` | string | Niveau de risque (`LOW`, `MEDIUM`, `HIGH`), présent si `COMPLETED`. |
| `recommended_action` | string | Action recommandée. |
| `trigger` | string | Origine du déclenchement. |
| `flags` | array | Indicateurs ayant contribué au score. |
| `ai_runs` | array | Exécutions d'agents IA. |
| `completed_at` | string | Date de complétion, présente si `COMPLETED`. |
| `created_at` | string | Date de création. |

## Cas d'usage

- Consulter le score de fraude avant de décider un claim.
- Suivre l'avancement d'une analyse en cours.
- Récupérer les indicateurs ayant déclenché une alerte.

## Bonnes pratiques

Si aucune évaluation n'existe, l'endpoint retourne `404`. Créez d'abord une évaluation avec `fraud-assessment-create`. Pour consulter une évaluation précise par son identifiant, utilisez `fraud-assessment-by-uuid`.
